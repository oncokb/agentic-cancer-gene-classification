i How to read these plots — a visual check on live cBioPortal data, not a reproduction of our test
  • Use the "Compare across all 32 cancer types" link for cross-cancer comparison; single-cancer plots auto-scale their y-axis.
  • The "mRNA vs Dx" links use detailed diagnosis categories, which are subdivisions of a cancer type and can be very small: a label such as "Breast Invasive Carcinoma (NOS)" is only part of BRCA, not the whole cohort.
  • For "Subgroup enriched" results, look at the cluster of high dots rather than the median.
  • cBioPortal can include metastatic or recurrent samples and repeat patients, so its sample counts differ from ours. The plot is a visual check, not a reproduction of our test.
  • The header's "altered in X%" is genomic alteration, not this expression result.
  • cBioPortal shows live data, which can differ from the release shown here.
